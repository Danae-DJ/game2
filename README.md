# game2
This game is a clasic game about the snake and the apple; the snake should eat the apple to grow and evit to crash with the wall.

## install
Node.js
Git
npm

## instructions
1. create a base of game with background
2. create the head of snake
3. create the buckle for the rotation of snake
4. create the funtion to creat the  body of the snake with 3 circules; they'll use the last position of the head and them.
5. create the apple that the snake'll eat and everytime change of random places
6. create the funtion to snake's body, everytime the snake eats an apple, its body grows.
7. crate the method to stop the snake with a wall
8. create the menu to choice a character and start/restar the game
9. configure the score
9. create the over of game and restart the game.
